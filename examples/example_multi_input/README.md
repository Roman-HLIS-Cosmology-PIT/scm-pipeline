# Running example with Multi-Input

To run this example you need to install the `scm-pipeline` but you also need the modified version of ceci that can be find [here](https://github.com/Roman-HLIS-Cosmology-PIT/ceci/tree/multi_input) and installed by:

```bash
pip install git+https://github.com/Roman-HLIS-Cosmology-PIT/ceci@multi_input
```

Then you can run the example from this directory by doing:

```bash
ceci ceci_dummy_stage.yml
```
